    // WHY_EV
    
  
    
    
    
      
    [OK] 즉시성
    
      
    입력할 때마다 rg/fd가 다시 돌며 결과가 실시간 갱신. 엔터 칠 필요 없음.
    
    
    
    
    
      
    [OK] 이름 + 내용
    
      
    파일명 매칭과 파일 내용 매칭을 한 화면에 합쳐 보여준다. 도구 전환 불필요.
    
    
    
    
    
      
    [OK] 한글 문서 관통
    
      
    .hwpx · .docx · .pdf 본문을 추출 — 한글/Word 앱 없이도 내용 검색·미리보기.
    
    
    
    
    
      
    [OK] 가볍다
    
      
    컴파일 없는 단일 스크립트. 의존성은 전부 brew 한 줄, 없으면 자동 설치.

        how it works
      
    
      
    

    검색어 입력
  │
  ├─ 일반 파일 ───────────→ rg 직접 검색
  │
  └─ *.hwpx / *.docx / *.pdf
        │
        ▼
     ev-extract  (unzip + 태그 제거)
        │
        ▼
     추출 텍스트를 rg 가 검색
        │
        ▼
     원본 파일 경로로 결과 표시
