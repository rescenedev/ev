# ev 수동 점검 체크리스트 (대화형)

테스트 폴더에서 `./ev` 실행 후:

- [ ] 시작하면 `search>` 프롬프트로 뜨고, 현재 폴더 하위 파일 목록이 바로 보인다.
- [ ] 글자를 입력하면 파일명 매치(경로)와 내용 매치(`파일:줄:열:내용`)가 함께 즉시 갱신된다.
- [ ] `Ctrl-F`로 범위가 전체→파일명만→내용만 순환되고, 프롬프트가 `search>`/`name>`/`text>`로 바뀐다.
- [ ] 우측 미리보기에 선택 항목 내용이 보인다(bat 설치 시 하이라이트 + 매칭 줄 강조, 없으면 cat).
- [ ] 텍스트가 아닌 파일(pdf/이미지 등)에서 `Enter`를 누르면 macOS 기본 앱으로 열린다.
- [ ] hwpx 파일을 선택하면 미리보기에 본문 텍스트가 보인다.
- [ ] hwpx 본문 단어로 검색하면 그 hwpx가 결과에 나온다(내용 검색).
- [ ] hwpx에서 `Enter`를 누르면 추출 텍스트가 pager(less)로 열린다.
- [ ] `Ctrl-O`를 누르면 선택 파일이 Finder에 표시된다.
- [ ] `Ctrl-H`로 숨김/.gitignore 포함이 토글된다(점(.)파일 등장/사라짐).
- [ ] 항목 선택 후 `Enter`를 누르면 $EDITOR로 해당 줄에서 열린다.
- [ ] `Ctrl-Y`로 경로가 클립보드에 복사된다(`pbpaste`로 확인).
- [ ] `?`로 미리보기 창이 토글된다.
- [ ] `Esc`로 종료된다.
- [ ] (선택) rg/fzf/fd 중 하나를 PATH에서 가린 뒤 실행하면 자동 설치를 안내/시도한다.
