# `ev` — Everything 스타일 TUI 검색 도구 설계

작성일: 2026-05-30
대상 플랫폼: macOS (zsh)

## 목표

Windows의 Everything처럼 "타이핑하는 즉시 결과가 갱신되는" 빠른 검색 경험을
터미널에서 제공한다. 단, 인덱싱 엔진을 직접 구현하지 않고 검증된 도구
(`rg`, `fzf`, `fd`, `bat`)를 조합한 얇은 래퍼로 만든다.

핵심 가치:
- 파일명 검색 + 파일 내용 검색을 한 화면에서 제공
- 입력할 때마다 실시간으로 결과 갱신
- 단축키로 두 모드 토글
- 우측 미리보기 + 에디터로 바로 열기

## 비목표 (YAGNI)

- 디스크 전체 인덱싱 / locate·mdfind 연동 (검색 범위는 현재 폴더 하위로 한정)
- GUI 앱
- 자체 파일 워처 / USN 저널류 변경 추적
- 컴파일 바이너리 배포 (단일 zsh 스크립트로 충분)

## 구현 형태

단일 zsh 스크립트 `ev` (저장소 루트에 위치). `fzf`를 메인 루프로 두고
`--bind`의 reload 액션으로 `rg`/`fd`를 매 입력마다 호출한다.

```
ev  (단일 zsh 스크립트)
 │
 ├─ fzf 메인 루프 (--ansi --reload --bind ...)
 ├─ [내용 모드]   입력 → rg --column --line-number --color=always {q}
 ├─ [파일명 모드] 입력 → fd --type f {q}
 ├─ Ctrl-F : 모드 토글 (프롬프트 라벨 변경)
 ├─ 우측 미리보기: bat(있으면) / cat 폴백, 매칭 줄로 점프
 └─ Enter : 선택 항목을 $EDITOR 로 해당 줄에서 열기
```

- 실행: `ev` (현재 폴더) 또는 `ev <경로>`
- 검색 범위: 인자 경로(기본=현재 폴더) 하위. 인덱스 없음.
- rg/fd가 `.gitignore`·숨김파일을 기본 존중. 토글로 포함 가능.

## 모드별 동작

### 내용 모드 (기본, rg)
- fzf 자체 fuzzy 필터는 끔(`--disabled`). rg가 실제 검색 담당.
- `change:reload(rg --column --line-number --no-heading --color=always -- {q} <root>)`
- 결과 줄 형식: `파일:줄:열:내용`
- 미리보기: 매칭 줄 중심 (`--preview-window` 의 `+{2}` 오프셋 활용)

### 파일명 모드 (fd)
- fzf fuzzy 필터 켜서 경로를 부드럽게 좁힘.
- `change:reload(fd --type f --color=always -- {q} <root>)` (또는 초기 전체 목록 후 fuzzy)
- 미리보기: 파일 처음부터.

## 키맵

| 키 | 동작 |
|---|---|
| `Ctrl-F` | 내용 ↔ 파일명 모드 토글 |
| `Ctrl-H` | 숨김파일/.gitignore 포함 토글 |
| `Enter` | 선택 항목을 `$EDITOR`로 해당 줄에서 열기 |
| `Ctrl-Y` | 경로를 클립보드로 복사 (`pbcopy`) |
| `?` | 미리보기 창 토글 |
| `Esc` | 종료 |

## 에러 처리 / 폴백

- **자동 설치:** 시작 시 의존성(`rg`·`fzf`·`fd`) 점검. 빠진 게 있으면
  `brew install <빠진 것들>`을 자동 실행해 설치한다.
  - 설치 직전 무엇을 설치할지 한 줄 안내 (조용한 시스템 변경 방지).
  - 환경변수 `EV_AUTO_INSTALL=0`이면 자동 설치를 끄고 안내만 한 뒤 종료(옵트아웃).
  - `brew` 자체가 없으면 자동 설치 불가 → Homebrew 설치 명령을 안내하고 종료.
  - 설치 실패 시 명확한 에러 후 종료.
- `bat`은 선택 의존성. 없으면 미리보기를 `cat`(줄번호용 `cat -n`)으로 자동 폴백.
  (자동 설치 대상에는 넣지 않음 — 없어도 동작하므로.)
- `$EDITOR` 미설정 시 `vi` 기본. 가능하면 `+줄번호` 점프(vim/nvim/code 분기).
- 인자 경로가 없거나 디렉터리가 아니면 명확한 메시지 후 종료.
- 빈 쿼리/0건 결과 → 깨지지 않고 빈 목록 표시.

## 엣지 케이스

- 파일명/경로에 공백·특수문자 → `{}` 치환은 항상 따옴표로 감싼다.
- 매우 큰 디렉터리 → rg/fd 성능에 위임. 추가 인덱스 없음.
- 바이너리 파일 → rg 기본 동작(건너뜀) 유지.

## 테스트 전략

- **단위 (bats):** 순수 헬퍼 함수 검증
  - 에디터 인자 조립 (`vim +123 file`, `code -g file:123` 등 분기)
  - rg 결과 줄 파싱 (`file:line:col:text` → 파일/줄 추출)
  - 미리보기 명령 선택 (bat 유무에 따른 폴백)
  - 의존성 점검 및 자동 설치 분기 로직 (brew 유무, 옵트아웃, 빠진 목록 산출)
- **통합 (bats):** 임시 디렉터리에 샘플 파일 생성 후, rg/fd 호출 래퍼가
  기대 결과를 내는지 비대화형으로 확인.
- **수동 체크리스트:** 대화형 fzf 부분 (모드 토글, Enter 열기, 미리보기,
  클립보드 복사, 숨김 토글).

## 디렉터리 구조 (예정)

```
ev                      # 메인 스크립트 (실행 가능)
lib/                     # 테스트 가능한 헬퍼 함수 분리 (source 됨)
  deps.sh                # 의존성 점검
  editor.sh              # 에디터 인자 조립
  parse.sh               # rg 결과 줄 파싱
  preview.sh             # 미리보기 명령 선택
test/                    # bats 테스트
  *.bats
docs/superpowers/specs/  # 본 설계 문서
```
